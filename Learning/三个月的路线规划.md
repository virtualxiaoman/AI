## 🧠 为什么这样排期？(学习路径逻辑)

1. **从“力大砖飞”到“精细雕琢” (Month 1):** 你熟悉 Transformer 基座，第一步必须了解它是如何被“放大”的（Scaling Laws），以及为了放大做了哪些微调（LLaMA 的 RoPE / RMSNorm）。接着，当模型大到难以单机运行，MoE 和对齐技术（RLHF/DPO）是必然的发展方向。这构成了现代 LLM 的底色。
2. **从“孤立大脑”到“接入世界” (Month 2):** 掌握了 LLM 基座后，你的下一个需求是如何在现实中**用**好它。LoRA 解决了你的算力受限问题，RAG 解决了模型的幻觉和知识陈旧问题，而 Agent/工具使用则赋予了模型“手和脚”。这是目前业界最主流的落地范式。
3. **从“单模态”到“多模态与未来” (Month 3):** 文本模型是“大脑”，多模态则是“眼睛和耳朵”。因为 LVLMs（如 LLaVA）严重依赖强大的 LLM 作为基座，所以必须放在最后学。同时，扩散模型与 Transformer 有不同的数学逻辑，放在最后能为你打开全新的生成式 AI 视角。

## 🚀 展开第一周学习任务：模型架构演进与缩放定律

本周的核心在于回答两个问题：**模型多大才够？在经典 Transformer 上做了哪些小修改成就了今天的 LLaMA？**

**每天学习安排（基于 3~6 小时）：**

* **Day 1-2: 缩放定律 (Scaling Laws)**
* **核心问题：** 算力有限时，应该增加参数量，还是增加训练数据？
* **必读论文：** *Training Compute-Optimal Large Language Models* (Chinchilla paper, 2022)。
* **关注重点：** 理解参数量 $N$ 和 Token 数量 $D$ 的最优比例。为什么说早期的 GPT-3 是“训练不足 (under-trained)”的？


* **Day 3-4: 现代开源基座的标杆 (LLaMA 架构)**
* **核心问题：** 为什么现在没人用绝对位置编码，而都在用 RoPE？
* **必读论文：** *LLaMA: Open and Efficient Foundation Language Models* (2023)。重点看 **Section 2 (Approach)**。
* **技术博客补充：** 搜索并阅读关于 **RoPE (旋转位置编码)** 和 **SwiGLU** 激活函数的数学原理解读。
* **关注重点：** 对比原版 Transformer，理解 Pre-normalization (RMSNorm)、RoPE 带来的相对位置感知优势，以及取消 Bias 层的工程意义。


* **Day 5-6: 注意力机制的显存优化**
* **核心问题：** 为什么生成长文本时显存容易爆？如何缓解？
* **必读论文/博客：** 搜索并理解 **KV Cache** 的概念，以及 **MQA (Multi-Query Attention)** 和 **GQA (Grouped-Query Attention, LLaMA 2/3 采用)** 的区别。
* **重点关注：** $O(N^2)$ 的注意力复杂度如何在推理时被 KV Cache 优化，GQA 如何在“推理速度”和“生成质量”间取得平衡。


* **Day 7: 代码验证与总结**
* **实践任务：** 打开 HuggingFace Transformers 库的 GitHub 源码，找到 `src/transformers/models/llama/modeling_llama.py`。
* **验证：** 粗读 `LlamaAttention` 和 `LlamaDecoderLayer` 类，不用自己写，只需将你在 Day 3-6 看到的 RoPE、RMSNorm 和 KV Cache 对应到实际的 PyTorch 代码中。

# 为什么这样排期

## 1. 先学“基础模型”，再学“行为”

很多人一开始学 Agent、RAG、LangChain。

这是错误顺序。

因为：

> 如果你不理解 LLM 本体，
> 后面的所有“系统技巧”都会变成 API 调包。

你需要先建立：

* scaling intuition
* architecture intuition
* representation intuition

---

## 2. RLHF 必须放在 LLM 之后

因为：

* alignment 是建立在 pretrained LM 之上的
* DPO/RLHF 本质是“行为塑造”
* 不理解 pretraining，就无法理解 alignment tax

---

## 3. 扩散模型放在最后

因为 diffusion 和 LLM 范式差异巨大：

* score matching
* denoising process
* latent space

如果太早学，会干扰你建立现代 LLM 主线。

## 为什么这样排期：从“造轮子”到“开车”，再到“修路”

你的五个学习板块，其实构成了一条清晰的因果链。我的安排思路是——

**第一阶段（第1–4周）：理解大模型的“物理层”**
没有对基座模型训练与推理的深刻理解，就无从判断后续所有技术的成本和可行性。缩放定律、密集/稀疏（MoE）架构、高效微调与量化，都直接回答“这些模型到底怎么跑起来的，为什么这么设计”。这一阶段是地基，学完之后你能从架构和经济性的角度评价任何一个新模型。

**第二阶段（第5–8周）：让模型“听话”并看见世界**
有了地基，再往上是对齐（让模型行为符合人类偏好）和多模态（让模型理解图像、生成图像）。对齐技术决定了 ChatGPT、Claude、DeepSeek 等产品的“性格”，多模态则是 2024–2026 最剧烈的能力泛化方向。并行学习这两块，是因为它们相对独立、又能互相印证：对齐解决“行为”，多模态解决“感知与表达”。

**第三阶段（第9–12周）：让模型“做事”并自我进化**
当前沿热点集中在 RAG、工具调用、Agent、推理时间扩展（如 o1/o3、DeepSeek-R1）。这是模型从“聊天”走向“行动”的关键一步，需要前两阶段关于能力与行为的全部知识。最后一周收尾于安全与未来展望，帮助你融入社区讨论。

整个过程始终按你的偏好：每周 1–2 篇高影响力论文/综述，辅以高质量博客/视频，代码实践重思路不重工程量。
